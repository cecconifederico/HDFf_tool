# Results Structure

This directory describes the outputs and data structures generated by the HFDncd estimation pipeline across four vigilance states (**Awake, N2, N3 and REM**) and three cortical areas (`A1`, `M1`, and `S1`).

## Execution Logic & Variable Output

The two run scripts use the same NCD computation and within-state statistical procedure. The sleep script repeats the analysis separately for each sleep stage.

| Analysis | Output File | MATLAB Table | Expected Dimensions |
| --- | --- | --- | --- |
| Awake | `HFDncd_awake.mat` | `HFDncd_awake` | 47 × 7 |
| Sleep | `HFDncd_sleep.mat` | `HFDncd_sleep` | 101 × 9 |

The expected dimensions refer to the reference datasets, assuming that all recording channels yield valid NCD results and no duplicates are processed.

Both files are saved in the current MATLAB working directory.

## 3. Automated Channel Label & State Parsing Rule

To systematically extract recording metadata, the scripts implement a string parsing rule based on the channel identifier.

- **Characters 1–2:** Electrode type (e.g., `GD`).
- **Characters 3–5:** Anonymized subject identifier (e.g., `013`).
- **Characters 6 to the penultimate character:** Local electrode identifier (e.g., `Lu_8`).
- **Final character:** Vigilance state identifier according to the dataset convention.

The vigilance state codes are:

- **W:** Awake (wakefulness).
- **N:** N2 (Non-REM sleep stage 2).
- **D:** N3 (Non-REM sleep stage 3).
- **R:** REM (Rapid Eye Movement sleep).

### Examples of Automated Parsing

| Channel Identifier | Electrode Type | Subject ID | Electrode | Vigilance State |
| --- | --- | --- | --- | --- |
| `GD013Lu_8W` | GD | 013 | Lu_8 | Awake |
| `GD029Rd10N` | GD | 029 | Rd10 | N2 |
| `GD029Rd10D` | GD | 029 | Rd10 | N3 |
| `GD009Rj08R` | GD | 009 | Rj08 | REM |

The wakefulness table does not contain a separate state column.

In the sleep table, the `State` column is assigned according to the area-stage file naming convention rather than being extracted from the channel suffix.

The Awake–REM comparison uses the final `R` character to identify REM channels.

## 4. Methodological Notes on `NCD_vs_K` Calculation

The same computational procedure is applied to wakefulness and sleep recordings.

For each recording channel, the signal is divided into valid segments. The NCD is computed independently for each segment and each subsampling factor.

The computational procedure includes:

1. **Anti-aliasing filtering:** A seventh-order causal Butterworth low-pass filter is applied to the original signal before subsampling.

2. **Subsampling:** The filtered signal is downsampled according to the selected subsampling factor `k`, retaining every kth sample starting from the first sample.

3. **Temporal representation:** The downsampled signal is retained at its reduced sampling rate without restoring the original temporal grid (`riportaBase = false`).

4. **Signal normalization and quantization:** The original and downsampled signals are independently standardized using z-score normalization, clipped at ±4 standard deviations, and quantized using 3 bits (8 quantization levels).

5. **Compression:** The quantized signals and their concatenation are compressed using the PPMd compressor (variant H, maximum context order 6).

6. **NCD computation:** The Normalized Compression Distance is computed from the compressed sizes of the original signal, the downsampled signal, and their concatenation.

7. **Channel-level aggregation:** For each subsampling factor, the median NCD value across valid segments is calculated and stored in `NCD_vs_K`.

### Mathematical Definition

$$
NCD(P,Q_k)=
\frac{C(PQ_k)-\min(C(P),C(Q_k))}
{\max(C(P),C(Q_k))}
$$

where:

- `C(P)` is the compressed size of the quantized original signal.
- `C(Qk)` is the compressed size of the quantized downsampled signal.
- `C(PQk)` is the compressed size of their ordered concatenation.

All compressed sizes are expressed in bytes.

### Quality Control

- Non-finite samples are excluded from valid contiguous signal segments.
- Contiguous padding-like intervals of at least 200 samples are treated as gaps according to the amplitude-based gap detection procedure.
- Signal segments containing 400 samples or fewer are excluded from the analysis.
- Segments without finite NCD values are excluded.
- NaN values are omitted during median aggregation.
- Channels without valid NCD curves are excluded from the output table.
- Duplicate sleep-channel records should be avoided.

Unlike the HFDf approach, HFDncd does not involve log-log linear regression or direct estimation of fractal dimension. Therefore, no regression-based R² quality threshold is applied.

The NCD values are not explicitly constrained to the interval [0, 1]. Values outside the ideal interval may occur due to the limitations of practical compression algorithms.

## 6. Subject-Level Aggregation

The primary output tables contain NCD curves at the channel level.

For statistical comparisons, subject-level NCD values are obtained by averaging the NCD values across recording channels belonging to the same subject, cortical area and vigilance state.

The primary statistical analysis is performed at:

```text
k = 2
```

Missing subject-area combinations are represented by NaN.

Only subjects with available NCD values for both conditions being compared are included in each paired statistical test.

The group NCD(k) curves for each cortical area and vigilance state are computed as mean ± standard deviation across recording channels.

The separate subject-level summary at the reference subsampling factor uses mean ± standard deviation across subject-level values.

Channel-level median and interquartile range are also reported.

## 7. Statistical Analysis & Visualization

### A. Common Within-State Analysis

The same analysis is performed separately for each vigilance state:

- Awake.
- N2.
- N3.
- REM.

The analysis includes:

- Example channel-level NCD curves.
- Example subject-specific curves obtained using the median across channels within each cortical area.
- Individual subject NCD curves obtained using the mean across channels within each cortical area.
- Mean NCD curves and standard deviations across recording channels.
- Subject-level mean NCD values and standard deviations at the reference subsampling factor.
- Within-subject scatter plots comparing cortical areas.
- Channel-level median and interquartile range (IQR).
- Paired Wilcoxon signed-rank tests.
- Effect size estimates.
- Exploratory statistical comparisons across all six subsampling factors.

### Cortical Area Comparisons

Within each vigilance state, the following cortical area comparisons are performed:

- S1 vs A1.
- M1 vs S1.
- M1 vs A1.

Two-tailed paired Wilcoxon signed-rank tests are performed using the approximate method when at least three paired observations are available.

The effect size is calculated as:

$$
r=\frac{|Z|}{\sqrt{n}}
$$

where:

- `Z` is the standardized Wilcoxon test statistic, when available.
- `n` is the number of paired observations retained in the comparison.

The effect size is unsigned. The direction of the difference can be assessed from the signed Z statistic or the median paired difference.

The primary statistical comparisons are performed at `k_stat = 2`.

Additional exploratory comparisons are performed across all six subsampling factors.

No multiple-comparison adjustment is implemented.

### B. Between-State Comparisons

Additional one-tailed paired Wilcoxon signed-rank tests are performed separately for each cortical area at `k_stat = 2`.

The directional hypotheses are:

- Awake > REM.
- REM > N2.
- N2 > N3.

Subjects are matched across vigilance states using their anonymized subject identifiers.

The Awake–REM comparison is implemented in the wakefulness script and requires the following sleep-state output file:

```text
HFDncd_sleep.mat
```

The REM–N2 and N2–N3 comparisons are implemented in the sleep-state script.

Both wakefulness and sleep-state results must be obtained using the same computational configuration.
