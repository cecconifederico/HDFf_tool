# Results Structure

This directory describes the outputs and data structures generated by the HFDncd estimation pipeline across different vigilance states: **Awake** and **Sleep**, mapped across three cortical areas (`A1`, `M1`, and `S1`).

## Execution Logic & Variable Output

The HFDncd pipeline computes the Normalized Compression Distance (NCD) between the original signal and its low-pass-filtered and downsampled versions across different subsampling factors.

Depending on the input dataset, the pipeline can be applied to two different processing modes:

1. **Awake Processing Mode:** Processes wakefulness recordings. The expected output table contains **47 rows × 7 columns**.
2. **Sleep Processing Mode:** Processes recordings from three sleep stages (N2, N3, and REM). The expected output table contains **101 rows × 7 columns**.

Both processing modes follow the same computational procedure and generate MATLAB `.mat` files containing the NCD curves and the corresponding analysis parameters.

---

## 1. Table Dimensions & Row Segmentation

### A. Awake State Table

For the reference wakefulness dataset, the output table is expected to contain **47 rows**, corresponding to the recording channels distributed across the three cortical areas:

- **A1 (Primary Auditory Cortex):** 10 channels (Rows 1 to 10)
- **M1 (Primary Motor Cortex):** 20 channels (Rows 11 to 30)
- **S1 (Primary Somatosensory Cortex):** 17 channels (Rows 31 to 47)

### B. Sleep State Table

For the reference sleep dataset, the output table is expected to contain **101 rows**, distributed across three sleep stages (**N2**, **N3**, and **REM**) within each cortical area:

- **A1 (Primary Auditory Cortex) — Total: 17 rows** (Rows 1 to 17)
  - *N2 Stage:* 6 rows
  - *N3 Stage:* 6 rows
  - *REM Stage:* 5 rows

- **M1 (Primary Motor Cortex) — Total: 45 rows** (Rows 18 to 62)
  - *N2 Stage:* 16 rows
  - *N3 Stage:* 16 rows
  - *REM Stage:* 13 rows

- **S1 (Primary Somatosensory Cortex) — Total: 39 rows** (Rows 63 to 101)
  - *N2 Stage:* 14 rows
  - *N3 Stage:* 14 rows
  - *REM Stage:* 11 rows

The actual number of rows may vary depending on the input dataset and the availability of valid signal segments. The indicated row ranges assume that all expected channels are retained and processed in the specified order.

## 2. Output Data Table Schema

The common output table structure consists of seven columns:

| Column Name | Data Type | Analytical Description / Meaning | Example |
| --- | --- | --- | --- |
| **Area** | `cell` | The specific cortical area of the recording. | `'A1'`, `'M1'`, `'S1'` |
| **Canale** | `cell` | Alphanumeric identifier of the recording channel. | `'GD013Lu_8W'`, `'GD029Rd10N'` |
| **TipoElettrodo** | `cell` | Electrode type extracted from the first two characters of the channel name. | `'GD'` |
| **SoggettoID** | `cell` | Anonymized subject ID extracted from characters 3 to 5. | `'013'` |
| **Elettrodo** | `cell` | Local electrode identifier extracted from the channel name, excluding the final vigilance state character. | `'Lu_8'` |
| **NCD_vs_K** | `cell` containing a `double` vector | Vector storing the NCD values computed for each subsampling factor. | `[NCD(k=2), ..., NCD(k=67)]` |
| **K_range** | `cell` containing a `double` vector | Vector containing the subsampling factors used in the analysis. | `[2, 5, 10, 20, 33, 67]` |

## 3. Automated Channel Label & State Parsing Rule

To systematically extract recording metadata, the pipeline implements a string parsing rule based on the `Canale` label.

The first components follow the same extraction logic across all vigilance states, while the final character identifies the physiological condition:

- **Characters 1–2 → `TipoElettrodo`:** Electrode type (e.g., `GD`).
- **Characters 3–5 → `SoggettoID`:** Unique three-digit subject identifier (e.g., `013`).
- **Remaining central substring → `Elettrodo`:** Local electrode identifier (e.g., `Lu_8`).
- **Final character → Vigilance State Code:**
  - **`W` → Awake:** Wakefulness recording.
  - **`N` → N2:** Non-REM sleep stage 2.
  - **`D` → N3:** Non-REM sleep stage 3 (slow-wave sleep).
  - **`R` → REM:** Rapid Eye Movement sleep.

The vigilance state is encoded in the channel name and can be identified from its final character.

### Examples of Automated Parsing

- `GD013Lu_8W` → Type: `GD`, Subject: `013`, Electrode: `Lu_8`, State: `W` (**Awake**).
- `GD029Rd10N` → Type: `GD`, Subject: `029`, Electrode: `Rd10`, State: `N` (**N2**).
- `GD029Rd10D` → Type: `GD`, Subject: `029`, Electrode: `Rd10`, State: `D` (**N3**).
- `GD009Rj08R` → Type: `GD`, Subject: `009`, Electrode: `Rj08`, State: `R` (**REM**).

## 4. Methodological Notes on `NCD_vs_K` Calculation

The same computational procedure is applied to wakefulness and sleep recordings.

For each recording channel, the signal is divided into valid segments. The NCD is computed independently for each segment and each subsampling factor.

The computational procedure includes:

1. **Anti-aliasing filtering:** A seventh-order causal Butterworth low-pass filter is applied to the original signal before subsampling.

2. **Subsampling:** The filtered signal is downsampled according to the selected subsampling factor `k`.

3. **Temporal representation:** The downsampled signal is retained at its reduced sampling rate without restoring the original temporal grid (`riportaBase = false`). Consequently, the original and downsampled signals have different lengths.

4. **Signal quantization:** The original and downsampled signals are independently standardized using z-score normalization, clipped at ±4 standard deviations, and quantized using 3 bits (8 levels).

5. **Compression:** The quantized signals and their concatenation are compressed using the PPMd compressor (variant H, maximum order 6).

6. **NCD computation:** The Normalized Compression Distance is computed from the compressed sizes of the original signal, the downsampled signal, and their concatenation.

7. **Channel-level aggregation:** For each subsampling factor, the median NCD value across valid segments is calculated and stored in `NCD_vs_K`.

Segments containing 400 samples or fewer are excluded from the analysis.

Segments without finite NCD values are excluded, while `NaN` values are omitted during median aggregation.

Channels without valid NCD curves are excluded from the output table.

Unlike the HFDf approach, HFDncd does not involve a log-log regression or a direct estimation of fractal dimension. Therefore, no regression-based R² quality threshold is applied.

## 5. Analysis Parameters & Saved Variables

For wakefulness recordings, the primary output table `NCDf_totale_1` is saved in the following MATLAB file:

```text
NCDf_totale_curves.mat
```

The reference computational configuration for both wakefulness and sleep is defined by the following parameters:

| Variable | Description | Reference Value |
| --- | --- | --- |
| `ks` | Subsampling factors | `[2, 5, 10, 20, 33, 67]` |
| `fc_Hz` | Butterworth low-pass cutoff frequencies (Hz) | `[35, 14, 7, 3.5, 2, 1]` |
| `n_bits` | Number of quantization bits | `3` |
| `riportaBase` | Restoration of the original temporal grid | `false` |
| `Fs` | Original sampling frequency (Hz) | `200` |

The correspondence between subsampling factors, cutoff frequencies, and sampling frequencies after subsampling is reported below:

| Subsampling Factor (k) | Cutoff Frequency (Hz) | Reduced Sampling Frequency (Hz) |
| --- | --- | --- |
| 2 | 35 | 100 |
| 5 | 14 | 40 |
| 10 | 7 | 20 |
| 20 | 3.5 | 10 |
| 33 | 2 | 6.06 |
| 67 | 1 | 2.99 |

These parameters ensure traceability and reproducibility of the computed NCD curves.

## 6. Statistical Analysis & Visualization

The pipeline provides channel-level and subject-level NCD values that can be used to investigate neurodynamic differences across cortical areas and vigilance states.

The analysis includes:

- NCD curves across subsampling factors for individual recording channels.
- Subject-specific NCD curves for each cortical area.
- Mean NCD curves and standard deviations for each cortical area.
- Subject-level NCD values at the reference subsampling factor (`k = 2`).
- Within-subject scatter plots comparing cortical areas.
- Paired Wilcoxon signed-rank tests.
- Effect size estimates.
- Median and interquartile range (IQR).

### Cortical Area Comparisons

Within-subject statistical comparisons can be performed between the following cortical areas:

- S1 vs A1
- M1 vs S1
- M1 vs A1

These comparisons can be conducted separately for each vigilance state:

- Awake
- N2
- N3
- REM

Subject-level NCD values are obtained by averaging the NCD values across recording channels belonging to the same subject and cortical area.

### Vigilance State Comparisons

Subject-level NCD values can also be used to investigate differences between vigilance states within the same cortical area.

The reference subsampling factor for statistical analysis is `k = 2`.

Additional exploratory statistical comparisons can be performed across all six subsampling factors, without correction for multiple comparisons.

Statistical tables are generated in the MATLAB workspace and are not automatically included in the primary output file by the awake run script.

Subject-specific figures can optionally be exported as PNG files.
